About

What this is

Footnote is a personal portfolio project. An agent reads SEC filings and answers questions about them, citing the quotes behind its answers. Its answers are scored against baselines that use the same model, on the FinanceBench open sample, with intervals that resample whole companies.

Sources and licenses

  • Questions and reference answers: the FinanceBench open sample by Patronus AI, PatronusAI/financebench, licensed CC BY-NC 4.0. Paper: Islam et al., "FinanceBench: A New Benchmark for Financial Question Answering", arXiv:2311.11944.
  • The filings are the companies' public documents. This site does not republish them: it shows short quotes (at most 400 characters), each attributed to its filing and page, and links to the source.
  • Code: MIT license.

Page references

A reference reads "page N of the benchmark PDF". N is the benchmark's zero-based page index plus one (page_index + 1), so it counts pages the way a PDF viewer does. It can differ from the page number printed on the filing.

What the grounding check proves

Every quote the system cites appears on the cited page of the filing, after normalizing whitespace, line breaks and hyphenation. The final numeric answer is a correct rounding of a number in a cited quote, or the result of a logged calculation over quoted numbers or the exact results of earlier such calculations (plus small constants such as /2, x100 and x365). A figure counts with either sign: a value in parentheses or with a minus sign is the same figure. For the units usd, count and other, a quoted number and a calculation result may each be scaled by a power of 1,000 (thousands, millions, billions); percent and ratio take no scale, and a percent may also be a calculation result times 100, never a quoted number times 100. Numbers in the explanation text are not checked. The check does not prove a number means what the answer says (units, periods); correctness is the grader's job, and the grader measures it.

The check applies differently to each system. The agent checks its own answers before it submits them and has a calculator. The baselines are checked only afterwards, for information, and they are checked without a calculator, so an answer that needs arithmetic (a margin or a ratio, for example) cannot be traced to its quotes even when the quotes are on the page. The no-documents system has no pages to cite. The no-documents system is not checked. The "unsupported" failure type applies only to the agent, and "retrieval miss" applies only to systems that read pages. Failure types therefore differ by system.

How answers are graded

Code grades an answer only when the question is a metrics-generated one, its reference answer is a single number, and the system's answer gives a structured final value (number and unit); the match uses a stated tolerance. Every other answer is judged by a separate language-model grader that sees the question, the reference answer and the system's answer. Where grader agreement was checked against reference labels written by an AI, the figures are AI-reference estimates, not human agreement rates.

Limitations

  • The sample is small, and questions cluster by company, so intervals are wide.
  • Every system is told which filing a question is about. This does not test finding the filing.
  • Development runs informed design choices and are labeled exploratory. Claims of difference rest on the test split, which each system family ran once.
  • Grading by a model can be wrong in both directions.
  • The 2023 paper numbers use different models, human grading and different retrieval setups, so they are context only.
  • Source links are checked once and fall back to an SEC EDGAR search when a link is dead.
